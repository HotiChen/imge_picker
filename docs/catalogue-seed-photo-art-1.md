# 平台商品種子資料：印像網（photo-art-1.com）

資料來源：印像網商品頁，2026-10-10 讀取。檔案：`worker/seed/photo-art-catalogue.mjs`；匯入：`worker/seed/import-catalogue.mjs`（預設乾跑）。

## 這份資料怎麼來、不是什麼

- **範圍**：相本 45 個、換照框盒 1 個（網站歸在相本，類型為印件）、相框類 27 個（無框畫、放大框、桌框），共 73 個商品、91 個規格。網站上的重複上架已合併（《連心》353/354；《布料水晶相本》8×8 的 121/123/181）。
- **沒匯入**：謝卡 9 個、婚用周邊 15 個（簽名綢、箱盒、相片沖洗、手提袋等）、喜帖（網站目前沒有商品）。目錄的 kind 只有 print / album，這些放不進去，要的話再決定。
- **價格**：用網站的「暖心價」同時當 vendor_cost 與 platform_price。這是顧客在印像網的零售價，**不一定是你的進貨價**，請照實際成本改。
- **分類**：目錄沒有分類欄位。分類寫在說明第一段（例如【相本›婚紗相本】），商品順序也依分類排列。若要真正的分類欄位，要加 migration + Worker 改動，目前不在 backlog 的主線上，沒做。
- **出血 bleed_mm**：網站沒有公布出血或解析度，全部留空（空值＝0 mm）。**請向印像網問各尺寸的出血值**後在 operator 頁填入。網站有公布的是內頁跨頁尺寸與封面尺寸，已寫進規格標籤與說明。
- **加頁價 extra_page_price**：網站有兩個互相矛盾的數字（規格表如 12×12 $160，加購區 $320），沒有擅自選一個，兩個都寫在說明裡，欄位留空。
- **頁數**：min_pages 設為網站的「基本頁數 15P」（跨頁計）；max_pages 不設，因為「加頁上限 25P」不確定是總頁數還是加頁數。
- **推算價（⚠）**：網站詳情頁只顯示預設（最大）尺寸的價格，列表頁顯示較小尺寸的價格。多尺寸商品的小尺寸價格是用這兩頁配對、或用《光遇》系列的尺寸價階推出來的（6×8 $1380、8×8 $1730、8×11 $2350、12×12 $3300）。共 14 個商品含推算價，說明裡標了「價格待確認」。
- **無框畫**：網站三種尺寸（16×24、20×30、24×35 吋）共用一個標價，只建立最小尺寸 16×24 的規格；其他尺寸價格請確認後在 operator 頁新增。
- **停售**：《黛菈》《雅漾》《寵愛》與出清的水晶婚禮面板會先建立再下架（共 4 個）。

## 套用方式

```
node worker/seed/import-catalogue.mjs                       # 乾跑，只列出計畫
OPERATOR_TOKEN=... node worker/seed/import-catalogue.mjs --apply
```

套用前需已在 D1 Console 跑過 `2026-10-06-product-min-pages.sql`（相本都帶 min_pages）。名稱已存在的商品會跳過，所以重跑不會重複建立，也不會蓋掉你在 operator 頁改過的內容。
